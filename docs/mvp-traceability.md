# MVP traceability matrix

Maps every MVP story in `docs/Plastoids_Blueprint.md` §26 (A1–I1) to the endpoints that implement it and the automated tests that cover it, and the ten illustrative ledger entries in §18 to the tests that exercise them.

Generated 2026-11-21 by reading the story table, every `Map*`/`.WithName(` registration under `src/Modules/*/Features` and `src/Modules/*/*Module.cs`, and every test method name under `tests/`. Nothing was built or run.

## Conventions

- **Routes** are relative to `/api/v1` (mounted in `src/Plastoids.Api/Program.cs`). The module group (`/identity`, `/catalogue`, `/tutors`, `/bookings`, `/payments`, `/lms`, `/certificates`, `/sponsorship`, `/applications`, `/payouts`, `/notifications`, `/admin/...`) is included in each route.
- **Slice folder** is relative to `src/Modules/`.
- **Tests** are `file::method`, relative to `tests/`. Project prefixes: `IT` = `Plastoids.IntegrationTests`, `Identity` = `Plastoids.Modules.Identity.Tests`, `Marketplace` = `Plastoids.Modules.Marketplace.Tests` (Catalogue + Tutors domain), `Sessions` = `Plastoids.Modules.Sessions.Tests` (Booking + live), `Learning` = `Plastoids.Modules.Learning.Tests` (Lms + Certificates), `Money` = `Plastoids.Modules.Money.Tests` (Payments + Ledger), `Payouts` = `Plastoids.Modules.Payouts.Tests`, `Sponsorship` = `Plastoids.Modules.Sponsorship.Tests` (Sponsorship + Applications), `Notifications` = `Plastoids.Modules.Notifications.Tests`, `BackOffice` = `Plastoids.Modules.BackOffice.Tests`, `Arch` = `Plastoids.ArchitectureTests`.
- **Status**: `covered` = every server-testable acceptance clause has an automated test; `partial` = at least one server-testable clause has none; `gap` = nothing exercises the story. Clauses that are operational (latency SLOs, delivery percentages, "within N hours") or purely client-side (mobile layout, taps, offline playback) are excluded from the status judgement and listed in the Gaps section.
- **Story-ID citations.** No test *method name* carries a story ID. Four tests cite a story in a comment: `IT/SponsorshipAndApplicationsTests.cs` cites F1, F3 and F4 inline; `IT/BackOfficeTests.cs` cites I1 in its class summary. Every other story is mapped to the nearest covering test(s). Source slices do cite stories in XML summaries (e.g. `Story A1` in `Identity/Features/Auth/VerifyOtp/VerifyOtpHandler.cs`), which is how the slice column was confirmed.
